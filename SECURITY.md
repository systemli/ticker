# Security Policy

## Supported Versions

Only the latest 3.x release receives security updates. Please upgrade before reporting an issue
against an older version.

| Version | Supported          |
| ------- | ------------------ |
| 3.x     | :white_check_mark: |
| < 3.0   | :x:                |

Released versions are listed on the [releases page](https://github.com/systemli/ticker/releases).

## Reporting a Vulnerability

Please report security issues privately to <support@systemli.org>, or via
[GitHub's private vulnerability reporting](https://github.com/systemli/ticker/security/advisories/new).

Include the affected version, reproduction steps, and the impact you expect. We will confirm receipt
and keep you updated while we work on a fix.

Please do not open a public issue for an unfixed vulnerability.
